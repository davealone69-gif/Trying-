# CHANGELOG - MANDELA MATRIX OS

All notable changes to the Mandela Matrix OS platform are documented in this file.

## [1.0.0] - 2026-07-31

### Added
- **Material Design 3 Mobile Navigation**: Material 3 bottom navigation bar, dynamic responsive navigation drawer, and desktop header rail with touch targets exceeding 48dp.
- **Categorized Free LLM Matrix**: Added categorized model selection grouping Cloud Models (Gemini 2.5 Flash, Gemini 2.5 Pro, Gemini 1.5 Flash), Community/API Models (DeepSeek R1 Distill, Llama 3.3 70B, Mistral 7B, Qwen 2.5 72B, Gemma 2 9B), and Local Models (Phi-3 local, Neural Rule Engine).
- **Offline AI Engine Fallback**: Zero-latency offline fallback engine supporting local neural rule processing and cached knowledge bank retrieval without network connectivity.
- **Mandela Reality & Effect Matrix Engine**: Alternate timeline comparison, memory shift analysis, divergence tracking, and community consensus scoring.
- **APK Auditor Suite**: Full inspection engine for APK manifests, permissions, signature schemes, SDK targets, and security build audits.
- **Developer Lab & Cyber IDE**: Code analysis, AI code generation, bug finder, refactoring suggestions, and project architecture inspection.
- **Image Tools & OCR Suite**: AI-powered image analysis, metadata extraction, image comparison, and OCR capabilities.
- **Swarm Builder**: Specialized multi-agent system featuring Architect, Developer, Tester, and Reviewer agents with collaborative planning and decision logs.

### Changed
- **Package Identifier**: Updated to official release package name `com.mandela.matrixos`.
- **Build Target**: Configured for Android 15 (Target SDK 35, Min SDK 26).
- **Security & Obfuscation**: Enabled R8 code shrinking, ProGuard rule enforcement, and server-side API key proxying for zero client secret exposure.
- **Accessibility & Display Scaling**: Optimized text auto-wrapping, overflow protection, and text shadowing for 150% display font scaling on Pixel 7 and Pixel 8 emulators.
